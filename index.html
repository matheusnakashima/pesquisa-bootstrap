Pesquisa sobre Bootstrap

Bootstrap é uma ferramenta que ajuda a criar sites. Ele tem classes prontas que facilitam a parte visual da página, sem precisar fazer todo o CSS do zero.

Exemplo de container

A classe container deixa o conteúdo centralizado e ajusta a largura de acordo com a tela.

Este é um exemplo usando a classe container.

Exemplo de container-fluid

Diferente do container normal, o container-fluid ocupa toda a largura disponível da tela.
