# Pesquisa sobre Bootstrap

Este repositório tem um exemplo simples feito com HTML e Bootstrap. A ideia é mostrar algumas ferramentas que ajudam na criação de páginas para a web.

## O que aparece no exemplo?

- **Navbar:** é o menu que fica na parte de cima da página.
- **Container:** organiza e centraliza o conteúdo.
- **Container-fluid:** ocupa a largura toda da tela.
- **Grid:** divide a página em colunas.
- **Cards:** mostram informações em pequenos blocos.
- **Responsividade:** faz o site se adaptar a telas de tamanhos diferentes.

## Como abrir

1. Baixe os arquivos ou abra o repositório no GitHub.
2. Abra o arquivo `index.html` no navegador.
3. Para ver a diferença no layout, diminua e aumente a largura da janela.

O projeto usa o Bootstrap 5.3.8 por CDN. Por isso, é preciso estar conectado à internet para carregar o estilo e o funcionamento do menu.
