# Exemplos de Bootstrap

Projeto demonstrativo para estudar classes do Bootstrap 5.3.8: containers, navbar responsiva, grid e cards.

## Como testar
1. Abra o arquivo `index.html` em um navegador com conexão à internet.
2. O Bootstrap é carregado por CDN, então é necessária conexão para visualizar os estilos e o menu.
3. Redimensione a janela para testar o menu responsivo e as colunas.

## Tecnologias
- HTML5
- Bootstrap 5.3.8 (CSS e JavaScript via CDN)
